## Objetivo
Decidir se valia fazer uma pós em Engenharia de IA Aplicada e, independentemente disso, montar
um projeto de estudo que cobrisse toda a grade do curso e servisse de portfólio.

## Problemas e soluções

### 1. A pós vale a pena para um dev sênior?
- **Sintoma:** dúvida entre pagar o curso ou estudar por conta.
- **Causa:** o conteúdo é atual e prático (LLMs, RAG, MCP, agentes), mas o certificado tem pouco
  peso para quem já tem 15 anos de experiência.
- **Solução:** usar a grade do curso como mapa de estudo e provar cada módulo com um entregável
  real, num projeto próprio.
- **Evidência:** mapeamento módulo → entregável em `docs/ROADMAP.md`.

### 2. Qual projeto?
- **Sintoma:** três ideias seguidas não empolgaram.
- **Causa:**
  - O copiloto de pagamentos era útil, mas sem graça.
  - O Project 722 já estava parado, com escopo grande demais.
  - O jogo de detetive com LLM era bom, mas não era o que se queria.
- **Solução:** IA jogando um jogo real num emulador. O jogo escolhido foi o **Pokémon Yellow**:
  - é longo, mensurável e determinístico (save states → evals reproduzíveis);
  - tem desmontagem completa (pret/pokeyellow);
  - e o Pikachu fraco contra o Brock obriga a planejar.
- **Evidência:** `docs/STUDY_NOTES.md`.

### 3. Qual modelo usar?
- **Sintoma:** Claude, Codex e uma GPU de 16 GB disponíveis, sem papel definido para cada um.
- **Solução:** arquitetura híbrida.
  - Claude como planejador e "professor".
  - Modelo local (Ollama) para as decisões frequentes e como alvo do fine-tuning.
  - Codex como ferramenta de desenvolvimento e jogador extra no benchmark via MCP.
  - Uma interface única troca o modelo por configuração.
- **Evidência:** `src/yellow_agent/models/`.

### 4. Como a IA "enxerga" o jogo?
- **Sintoma:** ler pixels da tela é caro e frágil.
- **Solução:** ler a RAM com os símbolos oficiais do pokeyellow (branch `symbols` do pret) e
  entregar ao modelo um JSON com mapa, posição, time, batalha, badges e a felicidade do Pikachu.
  A screenshot fica só para menus e diálogos.
- **Evidência:** `src/yellow_agent/state.py` e 21 testes com memória falsa.

### 5. O MCP do Python mudou
- **Sintoma:** `from mcp.server.fastmcp import FastMCP` quebrou.
- **Causa:** na versão 2 do SDK, o FastMCP virou `MCPServer` (`mcp.server.mcpserver`).
- **Solução:** usar a API nova e fixar `mcp>=2.0`.
- **Evidência:** `src/yellow_agent/mcp_server.py`.

## Decisões
- **Meta final:** zerar o Yellow sem intervenção. **Bônus:** speedrun.
- **Entregável principal:** uma página animada que explica cada mecanismo, alimentada por dados
  reais. Ela sai em 5 idiomas (pt-BR, en, es, zh, ar) e termina num replay interativo da IA
  jogando, no mínimo até vencer o Brock.
- **Este diário:** cada sessão registra problemas e soluções, e a página vira o relatório do
  projeto inteiro.
